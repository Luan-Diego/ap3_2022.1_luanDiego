📚 AP3 — Atividades e Práticas

Repositório dedicado ao armazenamento e desenvolvimento de atividades práticas realizadas durante a disciplina de AP3, na Universidade Federal Rural do Semi-Árido (UFERSA) — Campus Angicos.

O projeto reúne exercícios, experimentos e implementações desenvolvidos ao longo das unidades da disciplina, servindo também como registro da minha evolução no aprendizado de programação.

🎯 Objetivos

Desenvolver e aprimorar a lógica de programação.

Aplicar conceitos apresentados durante as aulas.

Praticar a implementação de soluções utilizando Java.

Organizar e documentar os exercícios desenvolvidos.

Acompanhar minha evolução técnica por meio de projetos práticos.

🚀 Executando os projetos

Para executar os exercícios desenvolvidos em Java:

Clone o repositório:

git clone https://github.com/Luan-Diego/ap3_2022.1_luanDiego.git

Acesse a pasta do projeto:

cd ap3_2022.1_luanDiego

Abra os arquivos utilizando uma IDE compatível com Java, como IntelliJ IDEA, Eclipse ou Visual Studio Code com suporte à linguagem.

Localize a classe principal de cada exercício e execute o programa.
